# آرشیو کلاس‌ها — نسخه ۶ فشرده و حرفه‌ای

این نسخه برای مخزن عمومی [PythonClassData](https://github.com/mmt315/PythonClassData) و GitHub Pages آماده شده است.

## تغییرات رابط کاربری نسخه ۶

- کوچک‌سازی مقیاس کلی رابط: هدر، عنوان، آمار، جستجو، کارت‌ها، فاصله‌ها و دکمه‌ها.
- بازطراحی بصری با ظاهر مینیمال‌تر و منسجم‌تر؛ سایه‌ها و افکت‌های شیشه‌ای ملایم‌تر شده‌اند تا صفحه حالت حرفه‌ای‌تری داشته باشد.
- حفظ فقط دو تم روشن و تاریک؛ رنگ‌ها، سطح کارت‌ها، ورودی جستجو، دکمه‌ها و پنجره پخش در هر دو تم به‌صورت هماهنگ تنظیم شده‌اند.
- حذف کامل فیلتر کشویی «همه کلاس‌ها / دارای فایل پایتون»؛ تمام کلاس‌ها نمایش داده می‌شوند و جستجو همچنان فعال است.
- چیدمان شبکه‌ای فشرده‌تر: حداکثر پنج ستون دسکتاپ، چهار ستون تبلت عریض، سه ستون تبلت و دو ستون موبایل.
- کوچک‌سازی کارت‌ها و دکمه‌های دانلود، حفظ نسبت ۱۶:۹ تصویر و جلوگیری از بیرون‌زدگی متن در نمایشگرهای کوچک.
- کنترل تغییر تم فقط بین روشن و تاریک جابه‌جا می‌شود. ترجیح کاربر ذخیره می‌شود؛ تنظیم قدیمی «نئون» به تم تاریک بازمی‌گردد.

## امکانات و اتصال

- نمایش فوری فهرست ذخیره‌شده و به‌روزرسانی پس‌زمینه؛ کش محلی تا ۲۴ ساعت.
- فهرست مخزن از Cloudflare Worker دریافت می‌شود؛ کش فرانت‌اند/CDN برای پاسخ فهرست و کش متادیتا در Worker حفظ شده است.
- بارگذاری تنبل تصاویر بندانگشتی هم‌نام هر کلاس با اولویت WebP و پشتیبانی از AVIF، JPG، JPEG، PNG و GIF.
- پخش در پنجره اختصاصی با `preload="metadata"`؛ با بستن پنجره منبع ویدیو متوقف می‌شود.
- دانلود ویدیوی MP4 و نمایش دانلود فایل `.py` فقط در صورت وجود فایل متناظر.
- فایل‌های پایتون فقط دانلود می‌شوند و در مرورگر اجرا نمی‌شوند.

## نام‌گذاری فایل‌ها

- ویدیو: `class_N.mp4`
- کد پایتون اختیاری: `class_N.py`
- تصویر بندانگشتی اختیاری: `class_N.webp`, `class_N.avif`, `class_N.jpg`, `class_N.jpeg`, `class_N.png` یا `class_N.gif`

فایل‌ها باید در ریشه مخزن باشند.

## انتشار روی GitHub Pages

فایل `index.html` را در مسیر انتشار سایت قرار بده. ویدیوها و فایل‌های پایتون از GitHub Pages و تصاویر از `raw.githubusercontent.com` بارگذاری می‌شوند.

## Cloudflare Worker

این نسخه به Worker فعلی متصل است:

- Worker: `https://py-class.game-m-m-t-s0.workers.dev`
- فهرست: `/api/classes`
- سلامت: `/health`

برای تغییرات ظاهری این نسخه، تغییر Worker لازم نیست؛ فایل `worker.js` برای همراهی با نسخه قبلی در ZIP حفظ شده است. در صورت بازنشر Worker، مقدار `FRONTEND_ORIGIN` باید origin سایت GitHub Pages یعنی `https://mmt315.github.io` باشد.

## تست محلی

در پوشه پروژه اجرا کن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. نحو JavaScript بررسی شده است؛ پخش و دانلود زنده باید روی هاست نهایی نیز آزمایش شود.
