# آرشیو کلاس‌ها — نسخه ۴ بهینه‌شده

این نسخه برای مخزن عمومی [PythonClassData](https://github.com/mmt315/PythonClassData) و GitHub Pages آماده شده است.

## بهینه‌سازی‌ها

- نمایش فوری فهرست ذخیره‌شده و به‌روزرسانی پس‌زمینه؛ کش محلی تا ۲۴ ساعت برای شروع سریع و کار در اختلال‌های موقت.
- کش فرانت‌اند/CDN برای پاسخ فهرست Worker با `stale-while-revalidate`؛ کش متادیتا در Worker به مدت ۱۰ دقیقه.
- کارت‌های هم‌اندازه با نسبت تصویر ثابت، بارگذاری تنبل تصاویر بندانگشتی و Decode غیرمسدودکننده.
- تصویر بندانگشتی خودکار از فایل تصویری ریشه مخزن با نام `class_N` و پسوند `webp`, `avif`, `jpg`, `jpeg`, `png` یا `gif`. اولویت با WebP است. اگر تصویر متناظر پیدا نشود، پس‌زمینه گرافیکی نمایش داده می‌شود.
- پخش در پنجره اختصاصی با `preload="metadata"` و بارگذاری منبع تنها یک بار هنگام بازکردن پخش‌کننده؛ با بستن پنجره، بارگیری متوقف می‌شود.
- دانلود مستقیم فایل‌های MP4 و فایل‌های `.py` متناظر، فقط وقتی فایل پایتون در مخزن وجود دارد.
- حذف نشانگر وضعیت Worker و متن توضیحی اضافه؛ دکمه پخش نارنجی با مثلث سفید در مرکز.
- در تم تاریک، منوی متنی فیلتر مخفی است؛ در تم روشن در دسترس می‌ماند.

## نام‌گذاری فایل‌ها

- ویدیوها: `class_1.mp4` تا `class_70.mp4`
- فایل پایتون اختیاری: `class_N.py`
- تصویر بندانگشتی اختیاری: `class_N.webp`, `class_N.jpg`, `class_N.jpeg`, `class_N.png`, `class_N.avif` یا `class_N.gif`

فایل‌ها باید در ریشه مخزن باشند. فایل‌های `.py` فقط دانلود می‌شوند و در مرورگر اجرا نمی‌شوند.

## انتشار روی GitHub Pages

فایل `index.html` را در مسیر انتشار سایت قرار بده. فایل‌های ویدیو و پایتون از مسیر GitHub Pages و تصاویر از `raw.githubusercontent.com` بارگذاری می‌شوند.

## Cloudflare Worker

این نسخه به Worker زیر متصل است:

- Worker: `https://py-class.game-m-m-t-s0.workers.dev`
- فهرست: `/api/classes`
- سلامت: `/health`

در تنظیمات Worker متغیر متنی `FRONTEND_ORIGIN` باید origin سایت باشد؛ برای GitHub Pages حساب `mmt315` معمولاً `https://mmt315.github.io` است (بدون مسیر و اسلش پایانی). Worker فقط متادیتا را ارائه می‌کند؛ فایل‌های ویدیو، تصاویر و پایتون از مخزن عمومی دریافت می‌شوند.

## تست محلی

برای تست، داخل پوشه `index.html` اجرا کن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. برای اطمینان از پخش ویدیوها، دسترسی عمومی مخزن و سازگاری MP4 با H.264/AAC را بررسی کن. کدها از نظر نحوی بررسی شده‌اند؛ پخش و دانلود زنده باید روی هاست نهایی نیز آزمایش شود.
