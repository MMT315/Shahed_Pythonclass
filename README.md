# آرشیو کلاس‌ها — نسخه ۳ (Frontend + Backend اختیاری)

این نسخه برای مخزن عمومی [PythonClassData](https://github.com/mmt315/PythonClassData) آماده شده است. فایل‌های ویدیو و پایتون باید در ریشه مخزن و با الگوی زیر باشند:

- `class_1.mp4` تا `class_70.mp4`
- فایل همراه اختیاری: `class_N.py`؛ دکمه دانلود آن فقط در صورت وجود فایل متناظر نمایش داده می‌شود.

## امکانات جدید

- جستجو با شماره کلاس (اعداد فارسی، عربی و لاتین)، فیلتر کلاس‌های دارای فایل Python و به‌روزرسانی دستی.
- بارگذاری تدریجی ظاهری (skeleton)، حالت خالی قابل‌فهم، پیام خطای روشن و استفاده از کش محلی کوتاه‌مدت هنگام اختلال.
- حفظ تم روشن/تاریک، طراحی واکنش‌گرا، رعایت `prefers-reduced-motion` و دسترس‌پذیری بهتر صفحه‌کلید و مودال.
- اعتبارسنجی سخت‌گیرانه نام فایل‌ها؛ هیچ نام دریافتی از API به‌عنوان HTML تفسیر نمی‌شود و فایل `.py` هرگز در سایت اجرا نمی‌شود.
- گزینه بک‌اند Cloudflare Worker برای کش‌کردن فهرست GitHub و کاهش فشار روی API عمومی.

## اجرای ساده (بدون بک‌اند)

فقط `index.html` را روی GitHub Pages یا هاست استاتیک قرار بده. برای اجرای محلی، در پوشه فایل اجرا کن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. در این حالت صفحه مستقیماً از GitHub Contents API فهرست ریشه مخزن را می‌گیرد؛ بنابراین محدودیت نرخ API همچنان ممکن است رخ دهد.

## اتصال به بک‌اند Cloudflare Worker تنظیم‌شده

این نسخه از قبل به Worker زیر متصل شده است:

- `API_BASE`: `https://py-class.game-m-m-t-s0.workers.dev`
- مسیر فهرست کلاس‌ها: `/api/classes`
- مسیر بررسی سلامت: `/health`

برای اینکه درخواست‌های مرورگر از GitHub Pages مجاز باشند، در تنظیمات همین Worker مقدار متغیر متنی `FRONTEND_ORIGIN` باید origin واقعی سایت فرانت‌اند باشد؛ برای حساب `mmt315` معمولاً `https://mmt315.github.io` است. این مقدار فقط origin است، بدون مسیر مخزن و بدون اسلش پایانی. اگر سایت را در GitHub Pages مخزن‌محور منتشر کرده‌ای، origin همچنان `https://mmt315.github.io` خواهد بود.

اگر مقدار `FRONTEND_ORIGIN` روی Worker با origin واقعی صفحه یکی نباشد، مرورگر درخواست API را به‌دلیل CORS مسدود می‌کند. می‌توانی ابتدا `https://py-class.game-m-m-t-s0.workers.dev/health` را باز کنی و سپس مسیر `/api/classes` را برای دیدن فهرست JSON بررسی کنی.

Worker فقط متادیتای فایل‌های عمومی را ارائه می‌کند؛ فایل ویدیو و پایتون همچنان مستقیماً از GitHub Pages دریافت می‌شوند. Worker هیچ راز یا کلید API لازم ندارد. کش متادیتا ۵ دقیقه است. این پروژه به‌صورت استاتیک حساب کاربری، احراز هویت یا محتوای خصوصی ندارد؛ بنابراین نباید فایل محرمانه‌ای در مخزن عمومی گذاشته شود.

## محدودیت‌ها و سازگاری

- کدک پیشنهادی ویدیوها: H.264/AVC + AAC در MP4 با `yuv420p` و `faststart`.
- دکمه `download` برای فایل‌های cross-origin تضمین نمی‌کند همه مرورگرها نام دلخواه را رعایت کنند؛ اگر دانلود به‌جای آن در تب جدید باز شد، از منوی مرورگر ذخیره کن.
- کش محلی تنها برای تجربه بهتر است و منبع حقیقت محسوب نمی‌شود.
- بررسی نحوی کد انجام‌پذیر است؛ برای تأیید نهایی باید Worker را منتشر و پخش/دانلود واقعی را در مرورگر هدف تست کرد.
